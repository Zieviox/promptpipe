# Names waiting for a decision

Names in the code that no design note answers: a verb outside the closed list (`3-terms.md`), a
word the list doesn't have, or an event outside the seven. `scripts/terms-check.py` reports these as
waiting and fails on any other name that breaks the list, so no new one comes in. Each is decided
by Gtex (a verb or noun added to the list, or a word the list already has), then renamed and taken
off this list. Made 2026-11-24 from the check; nothing here was renamed without a design note.
