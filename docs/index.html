What it does

Five things, done properly

Every chat is a file on your phone

Each chat is a plain Markdown file in a folder you choose. Nothing is locked inside an app, so you can read, back up and share your chats.

  • Pin the chats you use most
  • Folders, drag and drop, and select many at once
  • Back up with Git if you like

Your instructions go with every message

A profile is a short list of rows. Each row is a system prompt or a plugin. Switch rows on or off, drag them into any order, and your message goes where you put it.

  • Quick edit sits right above the message bar
  • Start from a starter profile, then make it yours
  • Export and share profiles

Find anything in one place

Find searches your chats and every setting, then lights up the control it points to. You never have to remember where something lives.

  • Always one tap away at the top
  • Shows the path and the shortcut
  • Shortcut keys on desktop, buttons on your phone

Plugins add what you need

Chat sites, memory, sub-chats and themes are all plugins. Updates are shown in the Library, and you pick which ones to apply.

  • Add plugin lists from friends or other sources
  • A warning before you trust a new source
  • Roll back an update if it breaks

Works with your other apps

PromptPipe has a local address on your phone. Other apps that talk to AI can use it, so your profile applies there too.

  • The address and token live in Settings
  • Everything stays on your phone
  • Your profile name is the model name

Good to know

Straight answers before you start

Keep it safe

  • Use an account you can afford to lose. Sites may limit automated use.
  • Only add plugin lists (repos) from people you trust. Plugins are code, and they can read your chats.
  • Never add a repo from a random site.

What PromptPipe is, and is not

  • It is not an AI. It uses the chat sites you log in to.
  • It is not made by, or connected to, those sites.
  • It is free and open source, and it does not ask for an account with us.
  • Your chats are files on your phone. Nothing is uploaded by PromptPipe.
